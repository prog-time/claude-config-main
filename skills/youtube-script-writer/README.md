# youtube-script-writer

Пишет закадровый текст для YouTube-ролика от первого лица: разговорный
стиль, сторителлинг, сухой чёрный юмор, обязательная самоирония. Автор —
разработчик 5–10 лет опыта, рассказывает личные истории про разработку,
open source и карьеру. Вывод — цельный монолог для озвучки на 5–10 минут,
сохранённый в `.md` файл.

## Triggers

- «напиши сценарий», «сценарий для ролика», «сценарий для озвучки»
- «текст для ютуба», «текст для видео», «закадровый текст», «напиши монолог»
- "write a video script", "youtube script", "voiceover script"
- Описание личной dev / open-source / карьерной истории под ролик

## Does not trigger for

- Технические статьи и туториалы (use `blog-article-writer`)
- README / CHANGELOG (use `docs-quality`)
- Описания PR (use `git-pr`) и release notes (use `git-release`)

## Structure

- `SKILL.md` — workflow, правила тона, что запрещено
- `references/style-guide.md` — смысловые блоки, приёмы стиля, юмор,
  запреты, примеры «плохо → хорошо» (читается перед каждым сценарием)

## Ключевые принципы

- НЕ фиксированная структура — «смысловые блоки», нелинейность
- От первого лица, короткие абзацы, паузы, ремарки `(пауза)` / `(вставка мема: …)`
- Самоирония обязательна, юмор сухой, без клоунады
- Финал неидеальный: тихий / резкий / обрывающий / философский
- «Если сомневаешься — делай менее правильно, но более живо»

## Installation

Picked up automatically after `make install` at the repository root.
